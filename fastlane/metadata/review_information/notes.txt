An Operator account is required for live review data.

For review without credentials, launch the app with:

  -uiTestDemoMode YES

Demo mode supplies deterministic sample messages and makes no network request.
The Review screen demonstrates filtering and message review. On supported
hardware, the app can use Apple Intelligence to draft a transcription,
translation, and moderation recommendation; generated work is never submitted
without an explicit operator action.

The app is an outbound-only client. It does not run an HTTP server, listen on a
network port, include ads, or use analytics or third-party tracking.
