# App Store screenshots

Generated by `scripts/capture-screenshots.sh` from the app's demo mode
(`-uiTestDemoMode -uiScreenshotTab <review|settings>`).

- `ios/en-CA/` — iPhone (`iphone69_*`) and iPad (`ipad13_*`) PNGs.
- `mac/en-CA/` — macOS window captures (`mac_*`).

Regenerate:

```sh
scripts/capture-screenshots.sh ios   # iPhone + iPad simulators
scripts/capture-screenshots.sh mac   # macOS host (needs Screen Recording permission)
scripts/capture-screenshots.sh all
```

`fastlane upload_store_metadata` picks these up automatically when present.
